# Search practice

Dieses Verzeichnis ist absichtlich ein eigenes kleines Dart-Paket, damit
`dart run` nicht den `pubspec.yaml` des übergeordneten Projekts
`sorting-sandbox` verwendet.

Ausführen:

    dart run search_random_test.dart

Nicht `dart run search.dart` ausführen: Diese Datei enthält nur die beiden
zu implementierenden Funktionen und absichtlich keine `main()`-Funktion.
